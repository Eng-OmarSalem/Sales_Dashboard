## 📌 Overview

**Sales Dashboard** is a fully interactive Excel dashboard built to analyze sales performance across nearly **10,000 orders**, covering multiple cities, states, sales reps, and product categories.

The dashboard is powered by interconnected **Pivot Tables**, **Pivot Charts**, and **Slicers** — no VBA or macros required. Selecting any filter instantly updates every chart and KPI card on the dashboard.

---

## ✨ Key Features

- 🔢 **KPI Cards:** Total Sales, Returns, Net Sales, Discounts, Cost of Goods Sold (COGS), Total Customers, Total Orders.
- 🗂️ **Sales by Category:** Furniture, Office Supplies, Technology.
- 🌍 **Sales by Sales Rep & Region** (Central, East, South, West).
- 🏙️ **Top 10 Cities and Top 10 States in Sales**, with detailed bar charts.
- 📈 **Sales & Quantity Trend by Year** (2014–2017).
- 🥧 **Sales Breakdown by Sub-Category** (Binders, Chairs, Phones, Storage, Tables...) shown in a pie chart.
- 📊 **Sales by State & Category** in a combined stacked chart.
- 🎛️ **Interactive Slicers:** City, Category, Returned, Person — can be combined to drill into any data segment.

## 🗂️ Workbook Structure

| Sheet | Description |
|---|---|
| `Orders` | Raw data for ~9,900 orders (order date, customer, region, category, sales, profit, COGS...) |
| `People` | Sales reps responsible for each region |
| `Return` | Log of returned orders |
| `Shipping Cost` | Shipping cost per ship mode |
| `Pivot Calculations` | Helper pivot tables feeding the KPIs |
| `Dashboard Creation` | Dashboard layout settings |
| `Sales Dashboard Calculation` | Final calculations feeding the dashboard |
| `Profit Insights` | Additional profitability analysis |
| `Wire Frame` | Initial wireframe for the dashboard design |

## 🛠️ Tools & Techniques

- **Microsoft Excel** (Pivot Tables & Pivot Charts)
- **Slicers** for real-time interactivity across all dashboard elements
- **Power Query / Query Tables** for data preparation and connections
- **Excel Formulas** to calculate Net Sales, Discounts, and COGS

---

## 🚀 How to Use

1. Download `Sales_Dashboard.xlsx` from this repository.
2. Open it in Microsoft Excel (2016 or later is recommended for full feature support).
3. Use the slicers on the right side to filter by city, category, return status, or sales rep.
4. Watch every chart and KPI update automatically based on your selection.
